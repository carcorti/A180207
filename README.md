# A180207: exact enumeration through n=22

Carlo Corti, independent researcher, November 2026.

This computational package accompanies *Exact Enumeration of Four-Window
Permutations: OEIS A180207 through n=22*. The current manuscript is
[paper/A180207.tex](paper/A180207.tex), an English monolithic LaTeX source
with its bibliography included. The matching [PDF](paper/A180207.pdf) is supplied.

For n >= 1, a(n) counts permutations p of 0,...,n-1 for which there are n+3
nonnegative integers x such that p[i] = x[i]+x[i+1]+x[i+2]+x[i+3]. The manuscript
proves a residue-minimum criterion, uniqueness of the witness, decomposition at
the zero window, a weighted subset recurrence and an inclusion-exclusion count.
It also proves reversal evenness and a(n+1) >= 2*a(n).

The canonical data are [data/b180207.txt](data/b180207.txt): exactly n=1,...,22,
ending with a(22)=2055385215352. The historical OEIS prefix n=1,...,16 is
preserved separately as [data/known16.txt](data/known16.txt); these are not new
terms attributed to this work. The sequence was contributed by R. H. Hardin
on 15 August 2010. Carlo Corti's completed native computation supplies n=17,...,22.
The first unresolved index in this study is 23; source capacity through 24
does not establish any further term. The canonical b-file ends with exactly
two LF bytes and can be regenerated byte for byte from the native result.
See [OEIS A180207](https://oeis.org/A180207) and the manuscript bibliography
for historical attribution and related sources.

## Verify the package

From the package root, the bounded check is:

```sh
python3 -B check/verify.py
```

It first checks the exact payload inventory, archive members and original
identities, the complete retained result comparisons and b-file regeneration.
It then checks a temporary copy of the original completed native job with the
original executed binary, builds the public C source in temporary storage and
recomputes only n=1,...,6. It also builds the IE checker for n=1,2,6 and runs
the Python checker at 6. It leaves the package and original job unchanged.
Success prints `SMOKE_PASS` and `PUBLIC_VALIDATION_PASS`. Timeouts, nonzero
exits, missing, unexpected or changed payload files fail the command. Only
root `.git` metadata is excluded from the payload inventory; symlinks are
rejected. This is a bounded reproducibility check, not a new full enumeration
through 22 or evidence for a later index.

The default command needs Python 3.12+, GNU make, GCC/G++ 13, OpenMP and OpenSSL
3 development/runtime libraries on compatible Linux x86-64 hardware. The
unchanged build recipe uses `-march=znver4 -mtune=znver4`, GNU 128-bit integers
and link-time optimization. The retained native binary also requires compatible
instructions and `libcrypto.so.3`/`libgomp.so.1`; it is an identity-bound
historical artifact. It is not interchangeable with a newly compiled binary.
The recorded host was an AMD Ryzen 9 7940HS with 8 cores/16 threads and Linux
Mint 22.3, with GCC 13.3.0 and Python 3.12.3. Original kernel, compiler and
runtime details are indexed from `outputs/dev/env.json` in `proof/evid.tgz`.

For a standard-library-only integrity and recorded-evidence check, without
compilation or execution of a retained binary:

```sh
python3 -B check/verify.py --records
```

For safe restoration of the exact original evidence paths, choose a new
directory outside the package, for example the following nonexistent path:

```sh
python3 -B check/verify.py --restore /tmp/a180207-originals
```

The destination must not already exist. Restoration performs the integrity and
record checks first and does not execute the restored historical scripts.
Original scripts are preserved as provenance; some overwrite their historical
output locations and contain Python assertions. Their original known-term
qualification used the historical 16-term baseline. Use the public checker
above for bounded validation, including when Python optimization is enabled.
Restoring the old layout expands the compressed checkpoints; allow at least
128 MiB for restoration and additional temporary build space for smoke checks.

## What the retained evidence establishes

The native masked recurrence and the different inclusion-exclusion recurrence
agree at every n=1,...,22, with all 2^(n-1) label subsets visited by IE. The
unrestricted-window Python method has complete recorded cases 1,...,12,16,17
(the parameterized wrapper was qualified at 1,2,6); no claim is made for
13,...,15 or 18,...,22 by that method. Exhaustive predicate replay covers all
permutations through 9. Original side-DP diagnostics cover maximum indices
12,...,16; all 32768 F coefficients at 16 agree across prefix depths 0,...,4.
The corresponding original commands and results are indexed in `proof/evid.tgz`.

These methods share some proved mathematics and the C/C++ compiler family.
Local validation was performed through the same OpenAI/Codex maintenance
context; algorithmic separation does not mean verified third-party execution.
The manuscript distinguishes received review opinions from actual local runs
and gives the full AI-use disclosure. Private review reports are not numerical
certificates and are not included here.

The original native receipt records about 297 seconds and a tracked peak
allocation of 3486204032 bytes, not process RSS. Original IE/Python receipts
retain their actual timing and memory fields; unknown fields are not inferred.
The package check reuses these completed records. It does not rerun expensive
development fixtures or claim to reproduce experiments whose fixtures were
removed. Each archived original retains its original SHA-256 identity; public
smoke builds are separate binaries and never replace the historical identities.

## Rebuild the manuscript PDF

Use TeX Live with pdfLaTeX, Latin Modern, AMS packages, booktabs, geometry,
microtype and hyperref, plus Poppler for text comparison. From the package
root, compile into a new temporary
directory so that auxiliary files do not enter the public payload:

```sh
builddir=$(mktemp -d)
for pass in 1 2 3; do
  SOURCE_DATE_EPOCH=1794528000 FORCE_SOURCE_DATE=1 pdflatex -interaction=nonstopmode -halt-on-error -file-line-error -output-directory "$builddir" paper/A180207.tex || exit 1
done
if grep -Ei "(^!|warning([[:space:](]|:)|overfull|underfull|undefined)" "$builddir/A180207.log"; then exit 1; fi
pdftotext paper/A180207.pdf "$builddir/reference.txt"
pdftotext "$builddir/A180207.pdf" "$builddir/rebuilt.txt"
cmp "$builddir/reference.txt" "$builddir/rebuilt.txt"
```

The fixed epoch is 13 November 2026 at 00:00 UTC and stabilizes PDF dates.
The supplied PDF was built with pdfTeX 1.40.25 / TeX Live 2023 (Debian).
With a matching TeX environment, `cmp` checks the extracted text. PDF bytes
may differ after rebuilding because of generated identifiers or TeX/font
versions; `checks.sha256` identifies the exact distributed PDF. Rebuilds
require visual and log inspection. The final build log must contain no
errors or warnings.
